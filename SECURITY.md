# Security Policy

## Supported Versions

Security fixes are released for the latest minor version of `abduns/laravel-vcard`.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Email [werk@abduns.com](mailto:werk@abduns.com) with a description of the issue, the
affected version and, if possible, steps to reproduce it. You will get a reply as soon as
possible, and a fix will be released once the issue is confirmed.
